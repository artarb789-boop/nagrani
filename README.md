# На грани — прототип для Tabletop Simulator

Папка `C:\NaGrani` на компьютере — копия этого репозитория. Мост (`Запустить_мост.bat`) сам подтягивает изменения.

- `live/*.lua` — скрипты, которые выполняются в запущенной игре, как только файл изменился в репозитории.
- `NaGrani.json`, `NaGrani.png` — стол TTS; при обновлении мост копирует их в сохранения TTS.
- `images/` — картинки тайлов, карт и планшетов (стол ссылается на `file:///C:/NaGrani/images/`).
- `build/` — исходники: данные, рендер картинок, сборка стола.
- `Правила_пробника.md` — правила пробника.
